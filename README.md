# Dart Tracker

A private, two-person collector's catalogue of cigarette boxes from around the world.

Not about smoking — about the *journey* of acquiring beautiful objects and reliving the memories attached to them. Two curators, one shared cabinet.

## The experience
- **World map (home)** — every box pinned to the place it was found.
- **Gallery wall** — the collection hung like artworks on a white wall.
- **Specimen page** — each box as a catalogued piece: the object, where & when it was acquired, the memory, tasting notes.
- **Accession flow** — quickly add a new specimen from your phone.

## Design — "The White Cube"
A MoMA-style gallery: pure black on white, the box photography is the only color in the room, one soft shadow under each piece. Full brief in [docs/DESIGN_SYSTEM.md](docs/DESIGN_SYSTEM.md).
