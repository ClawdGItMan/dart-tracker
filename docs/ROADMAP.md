# Roadmap

## Phase 0 — Design (now)
Lock the White Cube look in Claude Design. Output: mockups for the specimen page, world map, gallery wall, and add flow. → see [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md).

## Phase 1 — Foundation (together, first)
Scaffold + design tokens + shared components + Supabase data model + auth + photo storage + app shell/nav. Merged to `main` before any parallel feature work begins. (No feature split yet — this is the shared base everything depends on.)

## Phase 2 — Features (parallel, split by owner)
- **Max:** World map home (pins, clustering, specimen popover) · Accession / add flow · Collection overview.
- **Friend:** Gallery wall · Specimen detail page (object stage, place & date, memory, tasting notes).

**Milestone:** the two of us can add real specimens and browse them across map + gallery + detail.

## Phase 3 — Polish & memory
Search / filter, the two-curator "yours / theirs / ours" split, small museum delights, empty states, and refinement passes against the mockups.

## Phase 4 — 3D specimens (later)
Swap the object-stage photo for a drag-to-rotate 3D box render. The object-stage frame is built in Phase 1 to accept this without a redesign.

## Out of scope (for now)
Public sharing, social features, accounts beyond the two of us, native apps. Keep it intimate.
